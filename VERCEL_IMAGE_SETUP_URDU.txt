DRIVE MART - VERCEL PAR CAR IMAGE UPLOAD SETUP

Project ka code fix kar diya gaya hai. Ab Vercel par image public/uploads
mein save nahi hogi; image Cloudinary par save hogi.

SIRF YE STEPS KARNE HAIN:

1) https://cloudinary.com par free account banayein aur login karein.

2) Cloudinary Dashboard / API Keys page kholein.

3) Wahan se "API Environment Variable" copy karein.
   Yeh kuch is tarah hoti hai:
   cloudinary://API_KEY:API_SECRET@CLOUD_NAME

4) Vercel mein apna Drive Mart project kholein.

5) Settings -> Environment Variables par jayein.

6) New variable add karein:
   Name:  CLOUDINARY_URL
   Value: Cloudinary se copy ki hui poori value

7) Environment mein Production, Preview aur Development tino select kar dein.

8) Save karein.

9) Vercel -> Deployments -> latest deployment -> Redeploy karein.

10) Website par admin login karke Add Car dobara try karein.

IMPORTANT:
- CLOUDINARY_URL ko GitHub par upload na karein.
- .env file GitHub par upload na karein.
- Variable add karne ke baad redeploy zaroor karein.
- Agar Cloudinary URL set na ho to website ab EROFS error ki jagah clear setup
  message dikhayegi.
